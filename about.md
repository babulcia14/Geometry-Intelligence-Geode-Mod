# Geometry Intelligence AI

Your AI Companion for Geometry Dash. Experimental Windows alpha.

The local Python model is a small causal Transformer trained from random weights.
Its conversational ability is limited. Live rankings and metadata are read from
real APIs and shown with sources. This mod never edits level objects or plays
the game. No paid API is required for the local model, Pointercrate or Geode.

Start the separate Python server before using the GI button. See README.md in
the source project for training, installation, privacy and test evidence.

This project contains AI-assisted code and AI-authored synthetic training data.
It has not been approved by the Geode index. Building or sideloading this package
does not establish compatibility with every other mod or satisfy publication
review requirements. An experienced human must review and test it before submission.
